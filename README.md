# Malware Analysis Fundamentals & IOC Extraction

## Project Overview
This repository covers foundational malware analysis methodologies, utilizing static signature parsing and dynamic behavior classification frameworks. It includes a comprehensive analysis report detailing core Indicators of Compromise (IOCs) alongside a Python script for hash signature extraction.

## Directory Structure
- `docs/`: Contains the detailed `malware_analysis_report.md` research file.
- `scripts/`: Python orchestration tool calculating cryptographic hash signatures.
